# Tensu

# 功能

1. 大模型供应商管理
   * 可以配置适配openai接口或者anthropic接口的供应商，提供自动获取模型或者自己添加模型；
   * 模型需要标记是否支持视觉、推理、工具；
   * 模型的推理选项分为两种，一种是thinking/non-thinking，一种是 none/low/medium/high/max/xhigh中的几个强度组合；
   * 模型也需要标注输入和输出的上下文大小
   * 允许同一个供应商添加多个密钥
   * 模型能力评估矩阵
2. 大模型网关，代理openai或者anthropic，
   * 无需支持协议互相转换，穿透即可；
   * 将所有的模型代理到同一个端点下，所有的模型按照：供应商-模型 的形式展示
   * 负载均衡，负载均衡分为同名模型负载均衡和同供应商不同的key负载均衡两种模式
   * 路由模型，路由模型名称可以自定义，路由模型分为两种模式
     * 影子模式：应用上选择该模型，可以在平台上切换模型
     * 路由模式：通过路由引擎，来自动将任务分配到不同的模型
       * 路由引擎：两部分组成，分别是配置小型的路由模型和内置的规则引擎，小型的路由模型没有配置，就默认走规则引擎。路由模型通过对用户的输入做意图识别和复杂度评估，来路由到对应能力的模型；
       * 规则引擎：特征检测，上下文大小检测
   * 上下文压缩，使用规则压缩，设计核心是CCR和无损压缩
     * JSON结构压缩
     * 日志模板提取
     * 基础去重
3. 审计
   * Token 记录，对话内容记录，输入输出Token计算，输入分为压缩前和压缩后，都要记录和计算
   * 缓存命中率计算
   * 不同模型输出速度的对比
   * 首令时间
   * 等等各种计数
4. 技术
   * 后端：AspNetCore 10 WebApi + EfCore + Sqlite/PgSql + Channel + MemoryCache
   * 前端：最新的React + Vite + TS + Ant Design + 组件化开发
   * 桌面端（暂不开发），Tauri2.0 作为壳子运行 webapi+wwwroot 托管
